# Histórias de usuário

| ID | História de usuário | Origem |
| ---- | ---- | ---- |
| US01 | Como síndico, quero cadastrar meu condomínio e minha conta para iniciar sua administração na plataforma. | F01 |
| US02 | Como morador, quero solicitar meu cadastro e vínculo com uma unidade para obter acesso à plataforma. | F02 |
| US03 | Como síndico, quero aprovar ou rejeitar solicitações de vínculo para controlar o acesso dos moradores ao condomínio. | F05, F21 e RN11 |
| US04 | Como usuário cadastrado, quero me autenticar para acessar as funcionalidades permitidas ao meu perfil. | F03 |
| US05 | Como morador responsável por uma unidade, quero cadastrar ou convidar outros moradores da mesma unidade para que eles possam solicitar acesso à plataforma. | F04 |
| US06 | Como morador autorizado, quero registrar uma denúncia anônima para comunicar uma ocorrência preservando minha identidade. | F06 a F09, F11 e F12 |
| US07 | Como morador autorizado, quero anexar imagens à denúncia para fornecer evidências que auxiliem sua análise. | F10 |
| US08 | Como morador, quero consultar uma denúncia pelo protocolo para acompanhar seu status e histórico de andamento. | F13 e F14 |
| US09 | Como administrador autorizado, quero listar e filtrar as denúncias do condomínio sob minha responsabilidade para organizar a análise das ocorrências. | F15 e F20 |
| US10 | Como administrador autorizado, quero visualizar os detalhes e as imagens de uma denúncia para compreender a ocorrência. | F16 |
| US11 | Como administrador autorizado, quero atualizar o status de uma denúncia para informar a evolução de seu tratamento. | F17 e F19 |
| US12 | Como administrador autorizado, quero registrar as providências adotadas para manter documentadas as ações realizadas. | F18 |
